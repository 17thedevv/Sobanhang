# User-Centered Design Skill

## Purpose
Đảm bảo thiết kế phù hợp với người dùng thực tế của dự án.

## Target User
- **Primary**: Chủ cửa hàng (Có thể không rành công nghệ, thường thao tác nhanh tại quầy).
- **Secondary**: Nhân viên bán hàng, Khách hàng (data actor).

## Rules
- Thao tác nhanh, ít bước.
- Dễ hiểu, feedback rõ ràng.
- Lỗi dễ sửa.
- Text trực tiếp, không bắt user nhớ quá nhiều.
- **KHÔNG** dùng terminology kỹ thuật cho end-user.
- *Ví dụ*: Ưu tiên "Thanh toán" thay vì "Submit transaction".

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
