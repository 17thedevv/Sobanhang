# Design System Thinking Skill

## Purpose
Coi toàn bộ frontend là một hệ thống nhất quán, giảm thiểu fragmentation.

## Rules
- Trước khi tạo component: (1) Tìm component tương tự (2) Reuse nếu phù hợp (3) Extend nếu có thể (4) Chỉ tạo mới nếu responsibility thực sự khác.
- Design tokens nên được tập trung cho: colors, spacing, radius, typography, shadows, breakpoints, z-index.

## Anti-patterns
- Không tạo mỗi page một: button style, card style, modal style, spacing, typography, color riêng.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
