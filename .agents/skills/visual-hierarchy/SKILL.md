# Visual Hierarchy Skill

## Purpose
Xác định sự ưu tiên hiển thị trước khi styling.

## Rules
Ưu tiên theo thứ tự:
1. Primary task
2. Critical information
3. Secondary information
4. Supporting information

Công cụ tạo visual hierarchy:
- Size, spacing, typography, grouping, alignment, contrast, position.

## Anti-patterns
- Không lạm dụng: colors, shadows, gradients, badges, animations.
- Mỗi màn hình phải có **MỘT** visual focal point rõ ràng.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
