# Form Design Skill

## Purpose
Tối ưu hóa trải nghiệm nhập liệu của người dùng.

## Rules
- Tối ưu: field ordering, labels, required states, defaults, validation, inline errors, submit behavior, keyboard behavior, autofill, confirmation.
- Minimize fields. Group related fields. Put important fields first.
- Đừng hỏi thông tin không cần thiết cho task hiện tại.
- **Error handling**: Error phải nói rõ vấn đề gì, chỉ user cách sửa, và xuất hiện gần field liên quan. (Không dùng câu chung chung như "Invalid input").

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
