# Mobile-First Design Skill

## Purpose
Thiết kế tối ưu cho trải nghiệm trên thiết bị di động (< 768px).

## Rules
Ưu tiên:
- Thumb-friendly interaction.
- Large touch targets.
- Bottom navigation & Bottom action areas khi phù hợp.
- Short content density.
- Minimal horizontal scrolling.
- One primary action.

## Anti-patterns
- Không chỉ "shrink desktop xuống mobile".
- Mobile có thể cần: reorder content, collapse secondary info, change navigation pattern, convert table to cards, convert sidebar to bottom sheet/drawer.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
