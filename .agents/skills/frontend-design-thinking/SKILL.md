# Frontend Design Thinking Skill

## Purpose
Core philosophy and starting point for any UI task. Ensures the agent thinks about user goals, information architecture, and interactions before writing code.

## Core Philosophy
Frontend không phải chỉ là "Đặt component vào đúng vị trí."
Frontend phải giải quyết: User -> Goal -> Information -> Decision -> Action -> Feedback.
Mọi UI decision phải phục vụ: user goal, task completion, clarity, efficiency, confidence, consistency.
Không thiết kế chỉ vì: "trông đẹp", "giống screenshot", "component này phổ biến", "AI thường làm như vậy".

## When to Use
Khi nhận một task UI mới hoặc thay đổi flow hiện tại. (Khởi điểm cho mọi UI task).

## Workflow (The 8 Questions)
Khi nhận một task UI, Agent phải suy nghĩ theo thứ tự:
1. **WHO**: Ai sử dụng? Vai trò gì? Kinh nghiệm công nghệ? Context sử dụng?
2. **WHAT**: User đang muốn làm gì?
3. **WHY**: Tại sao họ cần action đó?
4. **PRIORITY**: Action chính là gì? Action phụ là gì? Thông tin nào quan trọng nhất?
5. **FLOW**: User đến màn hình từ đâu? Sau action này đi đâu?
6. **FEEDBACK**: Hệ thống phản hồi thế nào? (Thành công, Loading, Error, Empty)
7. **DEVICE**: Mobile, Tablet, Desktop, Touch, Mouse, Keyboard?
8. **COST**: Có bao nhiêu bước? Bao nhiêu thao tác? Có thể giảm cognitive load không?

## Core Priorities
- Clarity > Decoration
- Usability > Visual novelty
- Consistency > Local optimization
- Task completion > Animation

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
