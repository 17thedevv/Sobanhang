# Responsive Design Thinking Skill

## Purpose
Responsive design không chỉ là thay đổi width, mà là thích ứng trải nghiệm (Adaptive UX).

## Rules
Cân nhắc 4 loại adaptation:
1. **Reflow** (xuống dòng)
2. **Resize** (đổi kích thước)
3. **Reorder** (đổi thứ tự)
4. **Remove / Reveal** (ẩn bớt hoặc hiển thị thêm thành phần)

*Ví dụ*: Desktop hiển thị Sidebar + Content + Cart. Mobile hiển thị Bottom navigation + Content + Cart drawer.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
