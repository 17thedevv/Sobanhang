# Empty State Design Skill

## Purpose
Thiết kế trạng thái khi không có dữ liệu để điều hướng người dùng làm bước tiếp theo.

## Rules
Empty state không chỉ là "No data". Phải giải thích:
- Tại sao trống?
- User nên làm gì tiếp?
- Primary CTA (Call to action).

*Ví dụ*: 
Tốt: "Chưa có sản phẩm. Thêm sản phẩm đầu tiên để bắt đầu bán hàng. [Thêm sản phẩm]"
Xấu: "Sản phẩm trống."

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
