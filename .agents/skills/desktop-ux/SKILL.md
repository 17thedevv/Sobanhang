# Desktop UX Skill

## Purpose
Thiết kế tối ưu cho trải nghiệm trên màn hình lớn (>= 1200px).

## Rules
Desktop cần tận dụng:
- Horizontal space.
- Multi-column layout.
- Persistent navigation.
- Data-dense presentation.
- Mouse interaction.
- Keyboard shortcuts (nếu hữu ích).

## Anti-patterns
- **KHÔNG** đơn giản hóa Desktop thành "Mobile UI + rất nhiều khoảng trắng".
- Desktop có thể hiển thị nhiều context cùng lúc.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
