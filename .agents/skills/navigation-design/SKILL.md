# Navigation Design Skill

## Purpose
Thiết kế hệ thống điều hướng dễ đoán, nhất quán và nhận thức được ngữ cảnh.

## Project Baseline
- **Mobile**: Bottom Navigation
- **Tablet**: Compact Sidebar / adaptive navigation
- **Desktop**: Full Sidebar

## Rules
- Agent **KHÔNG** được tự ý tạo nhiều navigation systems khác nhau cho từng page.
- Navigation patterns phải nhất quán toàn app.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
