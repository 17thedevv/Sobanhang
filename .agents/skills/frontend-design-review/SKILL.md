# Frontend Design Review Skill

## Purpose
Checklist cuối cùng trước khi báo UI Done.

## Checklist
- **Structure**: Hierarchy rõ? Grouping hợp lý?
- **Interaction**: Primary action rõ? Feedback đầy đủ?
- **Responsive**: Hoạt động tốt trên mobile, tablet, desktop?
- **Consistency**: Reuse design system hiện tại?
- **Accessibility**: Keyboard, touch, readable?
- **Cognitive Load**: Quá nhiều options/text/decisions?
- **Visual**: Alignment, spacing, typography, density?

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
