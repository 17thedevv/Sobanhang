# Visual Consistency Skill

## Purpose
Đảm bảo tính đồng nhất về mặt thị giác giữa các trang/category.

## Rules
Các màn hình cùng category phải có:
- Same heading hierarchy.
- Same spacing logic.
- Same button semantics.
- Same input styling, error pattern, interaction feedback.

## Anti-patterns
- Ví dụ: Primary button không được ở page A là filled, page B là outline, page C lại là gradient, trừ khi có semantic reason rõ ràng.

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
