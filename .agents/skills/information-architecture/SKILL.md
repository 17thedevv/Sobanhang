# Information Architecture Skill

## Purpose
Tổ chức thông tin và phân cấp chức năng rõ ràng trên mỗi màn hình.

## Rules
Agent phải phân biệt: navigation, hierarchy, content grouping, primary action, secondary action, contextual action.
- Mỗi screen phải có: clear purpose, clear primary action, logical grouping, predictable navigation.
- **Không nhồi tất cả functionality vào một screen** chỉ vì "đỡ phải chuyển trang".

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
