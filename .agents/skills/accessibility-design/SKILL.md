# Accessibility as Design Skill

## Purpose
Đưa accessibility vào tư duy thiết kế, không chỉ là phase cuối (code implementation).

## Rules
Ngay khi thiết kế phải cân nhắc:
- Contrast (độ tương phản).
- Readable font.
- Touch target đủ lớn.
- Keyboard navigation & Focus ring.
- Screen reader semantics, labels, error announcement.
- PWA/mobile UX không được hy sinh accessibility.

*(Lưu ý: Skill này làm việc song song với engineering skill 'accessibility' trong dự án)*

## Project Context
- **Project**: "Sổ Bán Hàng"
- **Primary User**: Chủ cửa hàng nhỏ
- **Core UX Principle**: "Quick to understand. Quick to act. Hard to make mistakes."
